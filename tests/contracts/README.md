# Cross-repository contract vectors

`protocol-v2-vectors.json` is a byte-identical copy of the frozen vectors that
the central planning repository owns:

```text
voice-stt-client/workspaces/einheitliche-triggerarchitektur/ARBEITSDATEIEN/
  10_AKTUELL/EINHEITLICHE_TRIGGERARCHITEKTUR/PLANUNG/VERTRAGSVEKTOREN/
  protocol-v2-vectors.json
```

The copy exists so the server suite runs in CI and in a container where the
client repository is not checked out. It is **not** a second source of truth:
`tests/unit/test_protocol_v2_contract.py` compares the copy against the
original whenever the environment variable

```text
VOICESTT_PROTOCOL_V2_VECTORS=<path to the planning file>
```

points at a readable file, and fails on any drift. AP-SRV-040 and AP-CLI-010
must use the same vectors; if the planning file changes, refresh this copy in
the same change.

Do not edit this file here.
