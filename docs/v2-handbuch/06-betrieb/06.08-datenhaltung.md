## 6. SQLite (H6-12..H6-15)

## 7. Hub (H6-16..H6-18)

Aufbau: Store (falls enabled) → configure → Queues file/stdout (10000) → control → 3 Daemon-Writer (File/Stdout/Control); schreibfähig vor Lifespan (starting persistierbar) (H6-16). emit: prüfen → redigieren → bauen → **SQLite zuerst** → cursor+control-commit → Mirrors (file/stdout-Queues); ohne Store interner Cursor (einziger store-loser kanonischer Fall). Prio 0 (audit/error/critical/schließende Transkription), 2 (performance), 1 (Rest): **Verdrängung, nicht Reihenfolge** (FIFO-Entnahme); Überlauf zählt (drop_counts). flush joint Queues+Control; close = flush→_closed→Queues+Sentinel→joins-5s→Sinks→Store (idempotent) (H6-16). Schalter-Asymmetrie (C-3): request/transcription/system-enabled nur Spiegel (Store weiter); performance=false → kein Event (H6-17). Ausfall: disabled/ready/degraded getrennt lesend/schreibend (available=ready; nur Write-Heilung≠Read); Schreibfehler → log + emit None (**kein Spiegel**); health.ok = metrics.ok AND logging_ready (ready unberührt); Historie/Live 503 event_store_unavailable (H6-18; Health → 06.x).
