## 3. Neustart (A6-01..A6-06)

Keine Restart-/Reload-/Update-Route (vollständige Routenliste geprüft); Neustart = Prozess/Container (A6-01/N-U6-05). Stop-Reihenfolge: event → Sessions remove/close → Scheduler (Lock gelesen) → joins ready/idle je 5s → audit/perf close → server.stopping → hub.close (flush); Stop-Fehler nur geloggt (kein Maskieren); Facades teilen Hub → emit nach close wirksam (A6-02). Scheduler-Stop je Lane: close (closed+notify) → join 10s → engine-close nur beendet; **kein Drain/Requeue** – eingereihte-nicht-gestarte Jobs Schicksal ungetestet (U6-01): kein graceful-drain versprechen (A6-03). Idle: Intervall min(30,timeout/4) (min 0,1s), nur idle-an; RuntimeError (Audio/Transkriptionen) → später erneut, sonst geloggt; Lifecycle mit Limit 2/1 (A6-04). Manuell unload (Thread): loading/busy (Speaker/offene API/Recorder) → 409; ohne Scheduler changed=false; sonst unloading→unloaded + stop/Rollback + gc; **ready bleibt** → ok true + state unloaded möglich (A6-05). Ready-Thread: wait_ready **ohne Timeout** → ready + server.ready (healthy/Modelle) + loaded/load_failed + Publish + startupErrors-Replay; Hänger = Dauer-nicht-ready undefiniert (U6-02) (A6-06).

Praxis: vorher /health (ready/ok/startupErrors) + /api/metrics (Sessions/Queue) + /api/models/management; Fenster einplanen (kein Drain; WS geschlossen); restart/replace (`restart server` / `up -d server`); nachher ready + (logging-gesund) ok + startupErrors leer/erwartet + Modelle + /api/v2/info (Version/Commit).

## 4. Modellwechsel (A6-07..A6-12)

**Nur PUT /api/models/active** (Thread; PATCH lehnt Modell/Engine/Sprache startup_only ab; Fehler 400/500; 409-Zweig „keine Sessions" tot C6-01 – kein 409-Verhalten dokumentieren) (A6-07). Switch: Allowlist/Coerce → Policy → Kroko-Bindung → Quiesce (minimum_ready sonst LKG+ValueError) → Snapshot → lokal-Verfügbar (sonst ValueError) → Diff (redigiert) leer=No-Op 200 false; Lock ready.clear; loading→LKG+ready+RuntimeError; ohne-Scheduler→übernehmen+ready+schreiben+false; sonst old.stop/close → new.start/wait180+healthy; fail→LKG+Rollback (gesund→ready+RuntimeError 500, sonst RuntimeError-ohne-ready); ok→ready+switched+Perf+persist+true. **Kein Busy-Guard** (anders Refresh/Quiesce C6-02) – Switch auch mitten im Betrieb; kein 409-Schutz; lange Laufzeit (180s + evtl 180s Rollback) (A6-08). Kein-Wechsel: leer 200 false; unbekannt 400; loading RuntimeError; lokal-fehlt ValueError (A6-09). Refresh (zweiter Pfad): Lizenz→Quiesce; Fehler/gleiche-Revision→LKG+refreshRequired+RuntimeError; **busy→LKG+409 (während Sessions)**; sonst swap/wait; fail→LKG+Rollback/evtl unloaded; 409 (A6-10). Reload: load→model/runtime/skipped; Runtime sofort + Modell-Thread; {runtime,models,skipped}; Fehler 400; Runtime-vor-Modell (Zustand prüfen) (A6-11). Kroko-Quiesce: refresh→probe CONCURRENT_IDENTITY; busy→RuntimeError (Unload-Text „nach Ende erneut"); frei→unload(kroko_transition)+refresh; pro/key→Conflict-vor-Änderung (Neustart); Status restartRequired/Reason/Pro-Felder (A6-12).

Praxis: Zustand lesen (active/lifecycle/readiness/refreshRequired/startupErrors); Weg wählen (direkt=active, Konfig=refresh); Fenster (Switch kein Busy-Guard); 400=Kandidat-verworfen, 500=Rollback prüfen (ready/active/error); nachher ready/ok/refreshRequired/Revision/metrics.

## 6. Cleanup (A6-15..A6-19)

JSONL opt-in/kanalweise/lazy pro Tag (max(0,int); 0 = nie): Cutoff = Schreib-Tag − days; nur *.jsonl<cutoff (offene ausgenommen); rmdir leer. Beispiel days=1 am 9.11.: ≤7. weg, 8.+9. bleiben (A6-15). SQLite lazy append/UTC-Tag (nur days>0): Watermark-UPSERT MAX je (channel,session) → DELETE<cutoff → commit; **kein VACUUM** (Datei schrumpft nicht; Freiseiten intern) (A6-16/U6-03). Retention live: PATCH retention → configure (neue Sinks+set_retention, alte schließen); 400-Regel wie PATCH (A6-17). **Kein Audio-Cleanup** (nur Schreiben Tag-Ordner; kein Parameter/Job; personenbezogen → Betreiber) (A6-18/U6-04). Atomar: .part→Quelle/bytes/sha→replace→finally-unlink; verifizierte wiederverwendet; Discovery skippt .-Präfix/.part/.staging (+snapshots) – Abbruch hinterlässt keine Schein-Modelle (A6-19).
