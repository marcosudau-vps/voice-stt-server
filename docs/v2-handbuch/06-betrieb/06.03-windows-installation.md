## 1. Worum geht es?

Belegter Windows-Weg = **Quellbaum-/venv-Setup, kein Produkt-Installer**: Checkout vorhanden → `.venv` (nur bei Fehlen, keine Aktivierung) → CPU-Torch aus CPU-Index **vor** editable → editable mit sechs Extras → optional Kroko-Builder → Start mit `voice-stt-server` (Defaults `0.0.0.0:8010`/`cpu`/`int8`) (W6-01/W6-02/W6-04/W6-14/W6-10). Skript erzeugt keine gepinnte Umgebung, keinen Dienst (W6-03/W6-18). Qualifikation läuft über Wheel-Pfad, nicht ps1 (W6-16; K6-19).

Reihenfolge: venv → CPU-Torch (Index) → editable+Extras → Kroko → Start. Torch-vor-editable ist funktional (sonst Standardindex-Torch) (W6-02).

Begriffe: venv (`.venv` eigener Interpreter/Pakete); editable (`pip install -e .`, Code-bindend, Befehle trotzdem); Extra (benannte Gruppe, z. B. `server`); Wheel (`cp312-win_amd64`); Constraint (Versionsbegrenzung, hier keine, W6-03); CPU-Index (`https://download.pytorch.org/whl/cpu`, W6-02).
