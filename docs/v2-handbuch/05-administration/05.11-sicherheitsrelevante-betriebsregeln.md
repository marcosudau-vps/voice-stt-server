## 3. Schlüssel/Loopback/offen (R5-01..R5-04)

Key setzen vor LAN (sonst extern 403, nicht 401). Nur ENV/CLI/Settings (kein .env-Lader); YAML top-level → Exit; PATCH startup_only → 400; leer falsy, whitespace truthy; nested Kroko-YAML ungeprüft. Loopback nur client.host (kein Forwarded/proxy_headers); Proxy=Tcp-Peer als deploymentspezifisches Beispiel (Host→Loopback, Bridge→403) (U5-01). /api/config (public_dict ohne Keys, Limits/Capabilities/startupErrors, adminAuthRequired≠offen) + /api/metrics offen.

## 4. Audio/Token/OpenAI/enabled (R5-05..R5-08)

WS ohne Auth (Query/accept+Handshake; Limits=Kapazität). Token 64Hex/86400/<=ungültig, RLock/prozessintern, Neustart leer, Ende ohne Wirkung. OpenAI ohne Key offen/ohne Audit; mit Key exakt `Bearer <k>` + 401 invalid_api_key + Audit; nur /v1. enabled startup-only (CLI/YAML); PATCH abgelehnt; Persistenz kann CLI überstimmen (C); POST disabled 404-code-null-vor-Auth + Event, GET 200.

## 5. Kroko/Status/Fehler/Health (R5-09/R5-15..R5-17/R5-12)

Kroko explizit modellgebunden 1x connect+recv 5s kein Retry; Start/Service synchron möglich; force/leer ohne Netz; fremd model_scope_mismatch. forceCommunity live/serverweit/persistent (Absicht, nicht Status); invalidiert synchron; Reconcile Daemon; Session ohne Einfluss. Pro/Key-Wechsel neuer OS-Prozess; release nur Lease; active≠läuft; Community setzt nicht zurück; kein Reset/exec. Key-Quellen wie oben; kein Log/Persistenz/Netz. /health 200; ok=metrics.ok AND logging_ready; ready Event; startupErrors/eventStore beachten.

## 6. Trennung/Limits/Transport (R5-18/R5-13/R5-14)

Ein Key alle 21 (keine Rollen; Log accessToken-Ausnahme; sonst nicht tauschbar). Kein 429/Lockout (Limits≠Auth). Kein TLS/CORS/TrustedHost/Redirect/Origin; 0.0.0.0:8010; extern lösen.

## 7. Lesen (R5-10..R5-12)

401 (mit Key: fehlt/falsch, auch Loopback/remote) vs 403 (kein Key konfiguriert + remote, nur Admin) vs Log-401 (ohne Header/Audit). 404: POST-disabled code-null vor Auth; GET 200; Framework-Pfad; model_not_found nach Auth. /health Liveness (Body ok/ready), nicht Readiness.
