## 1. Worum geht es?

Meldung hat Ort → Ort sagt Schicht: Build (Exit 1/BuildError/COPY) = Install; CLI-SystemExit-deutsch = Konfig; ok:false/startupErrors/sttReady = Modell; Warnung/Zähler = Audio; HTTP 400/401/403/404/409/500/503 = Auth/Inferenz; WS 1008/1011/1013 = Auth/Zulassung. **Symptom (exakt) → Prüfung (Exit/Endpunkt/Log/Zähler) → Ursache/Behebung (nur belegt).** Ablehnungen/Warnungen/Zähler, **keine Heilversprechen** (kein Retry/Download/Nachholen wo Code keins hat).

Sortierhilfe: „Transkripte brechen nach ~30s ab" = 30s-Pfad/recorded-Trim (F6-09/F6-10), kein Modellfehler. „Antwortet, aber nie Text" + ok:false = Ladefehler startupErrors (F6-17), kein Audio-Problem.
