## 2. Aktivierung/Phasen (GL9-01..14)

**Activation (GL9-01):** angenommene Vordergrund-Einheit mit Id/Sequence/Source, genau einer Phase. Nicht Session/Segment/Transkript.

**Phasen 5 (GL9-02):** idle, waiting_first_speech, segment_active, followup_wait, closing_input. Kein finalizing; INACTIVE nur Alias idle (C2).

**idle (GL9-03):** einzige Annahme-Phase; Snapshot null/false; nicht Session/Transkript-Ende.

**waiting_first_speech (GL9-04):** Initial-Fenster mit Deadline; refresh invalid_phase.

**segment_active (GL9-05):** Aufzeichnung mit Watchdog; refresh max; VAD kein Reset. Nicht Objekt Segment.

**followup_wait (GL9-06):** Nachfragefenster; refresh now+followup nie kumulativ; offen ohne Aufnahme.

**closing_input (GL9-07):** Barriere mit Context+Recovery; nur input_closed nach idle. Nicht Drain.

**activationId (GL9-08/C3):** kanonische UUID v2 (kompakt/Gross abgewiesen); Controller-Default hex ist v1-Pfad.

**Sequence/generation (GL9-09):** monoton nur Admission; generation Alias kein 2. Zaehler.

**Revision/Token (GL9-10/N1):** Revision nur wirksame Timer-Aenderung; Token vollstaendig sonst stale. Warnung erhoeht Version nicht Revision.

**Deadlines 4 (GL9-11):** initial_speech/followup/segment_watchdog/closing_recovery; monoton nie wall-clock.

**Watchdog (GL9-12):** Schutzfrist mit Warnung; Ablauf schliesst ganz (segment_watchdog_timeout) kein Folgefenster.

**Context (GL9-13):** unveraenderlich reason/cause/requestedBy; null bei Timer/Geraet.

**input_closed (GL9-14/C4):** abgeschlossener Close genau einmal; causedBy nur finish/cancel. Kein Beginn-Event (N2/U3).

## 3. Commands/Handshake/Snapshot (GL9-15..21)

**ack 15 (GL9-15/C1):** einzige Antwort mit ID; RESULT_CODES 15 geschlossen; accepted nur applied/no_change. Domänen-Reasons projiziert nicht Wire. settings_control.RESULT_* getrennt (nur stringgleich).

**commandId (GL9-16):** Client-UUID validiert nie umgeschrieben; ohne sie kein Slot/Ack.

**Replay (GL9-17):** MISS/REPLAY/CONFLICT je ID; Replay Original ohne Wirkung; Conflict ohne Effekt.

**Suppression (GL9-18):** configured/suppressed/effective; nur naechste Admission.

**Quellen (GL9-19):** manual/wake_word gleichrangig; Client nur manual; source auf Control verboten.

**Handshake/Close (GL9-20):** vor accepted keine Domaene; 4400/4406/4408/4409/1011, Timeout 10s, keine ID. 4400 ohne Nachricht.

**Admission/Snapshot (GL9-21):** Katalog einmal; Snapshot Projektion (pending nur inputClosed).

## 4. Events/Versionen/Settings (GL9-22..30)

**stateVersion (GL9-22):** sichtbare Aenderungen, nicht Controller.version; No-op zaehlt nicht; advance fuer Rest.

**eventId/Seq (GL9-23):** frisch/monoton; logical_key Retry = gleiches Event.

**18 Events (GL9-24):** activation.started/phase_changed/input_closed/completed/cancelled/failed/trigger_suppressed, segment.recording_started/ended, transcription.accepted/interim/completed/discarded/failed, watchdog.warning, wakeword.detected/availability_changed, settings.changed. Legacy projiziert Rest verworfen; kein transcription.cancelled.

**NON_STATE (GL9-25):** watchdog/suppressed/interim erhoehen nicht.

**2 Revisionen (GL9-26):** Session vs Server (overlay/revision); kein gemeinsamer; conflict +1 bei echter Aenderung.

**4 Policies (GL9-27):** live/next_activation/next_session/server_restart; Gruppenreihenfolge erste zaehlt.

**Latch (GL9-28):** Policy einmal Admission; spaeter wirkungslos.

**requested/effective (GL9-29):** Wunsch vs naechste Sicht; divergent bis Rebuild.

**Overlay (GL9-30):** einzig persistent; Start streng (Revision/Scope/keine Secrets).

## 5. Segmente/Ledger/Wake (GL9-31..38)

**Segment (GL9-31):** Einheit Id/Sequence einer Activation; v1 int v2 UUID.

**Terminals (GL9-32):** Segmente 4 (completed/discarded/cancelled/failed); Activations 3 (kein discarded).

**Drain (GL9-33):** Hintergrund nach Input-Close; Ledger Reihenfolge; keine Phase.

**Barriere (GL9-34):** Cancel neutralisiert spaeteren Text als cancelled; kein input_closed.

**Katalog (GL9-35):** Revision, kanonische id, Backend-Health; ein Backend je Auswahl.

**Nullpunkt (GL9-36):** Trailing Edge; release = Nullpunkt-preRoll geklemmt.

**Qualifikation (GL9-37):** minFrames qualifiziert, darunter finalisiert; erster gewinnt.

**Latch (GL9-38):** nach Admission genau ein detected; Freigabe bei activation_closed.

## 6. Betrieb (GL9-39..50)

**Engines (GL9-39):** nur faster_whisper/kroko_onnx, Default faster_whisper (kanonisch, kein fw-Alias; nur lower/-→_-Normalisierung); keine Aliasse, cpu hart.

**Lifecycle (GL9-40):** DISCOVERED/VALIDATED/LOAD_VERIFIED/MINIMUM_READY/NOT_READY final+realtime.

**Slots (GL9-41):** nur final/realtime; realtime max 1/Session; coalesced/stale Zaehler.

**Speicher (GL9-42):** low-memory vs balanced; Init serialisiert.

**Logging (GL9-43):** 4 Kanaele; transcript_mode none/final/full.

**EventStore (GL9-44):** SQLite-first append; cursor+Watermark; Zustand Schreib+Lese.

**Metriken (GL9-45):** /api/metrics Sessions/Scheduler/Modelle/limits; Latenzen count/avg/max/p50/p95 Fenster 256.

**Security (GL9-46):** Admin/Bearer/LogToken/Kroko getrennt.

**Interim (GL9-50):** optional stable/unstable/consensus; kein Pflichtschema/Guete.
