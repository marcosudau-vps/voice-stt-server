**hello 8 (WS8-04):** type hello, supportedProtocolVersions nicht-leere int-Liste (bool ab), clientVersion/Commit nicht-leer, clientRunId kanonisch UUID, requestedSession Objekt, trigger manual+wakeWord bool, wakeWordIds Liste (leer ok), runtimeSuppression manual+wakeWord bool. **3 Stufen (WS8-05):** Envelope-Fehler→4400 ohne Nachricht; keine Version→incompatible+4406; inadmissibel→rejected+4409; Exception→1011. Nie sessionId.

Kein extend (invalid); wake_word als source nie.

**ack (WS8-10):** {type,protocolVersion,sessionId,commandId,accepted,result,activationId,inputPhase,stateVersion,settingsRevision} + errors nur nicht-leer {field,code,message}; accepted nur applied/no_change; idle normalisiert; stateVersion 3 Fälle (closing-Eintritt/sichtbar-ohne-Event +1/sonst aktuell).
