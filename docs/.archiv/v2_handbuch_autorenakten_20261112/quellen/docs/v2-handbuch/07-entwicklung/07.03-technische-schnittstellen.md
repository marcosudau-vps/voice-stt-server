## 1. Worum geht es?

Vier Python-Schnittstellen, ein Fluss: **Recorder** (Fassade) → **Executor** (Naht) → **Fabrik** (2 Engines) → **Session** (Recorder+Adapter) → **create_app/main** (Verdrahtung/Start). Keine HTTP/WS-Protokolle hier (→ 04.x); keine Settings-Mechanik (→ 03.x); kein Verhalten (→ 02.x/06.x).

| Schnittstelle | Rolle | Wer ruft sie? |
|---|---|---|
| Recorder (`VoiceSTT.audio_recorder`) | Aufnahme-Fassade: Modell/Mikro/VAD in einem Objekt | Anwendung, Tests, Session |
| Engine (`transcription_engines`) | reine Transkription hinter schmalem Basisvertrag | Recorder, Server-Lanes |
| Session (`api_fastapi_server.server`) | eine Sitzung als Objekt: Audio rein, Zustand/Snapshot raus | WS-Schicht, Service |
| Server (`api_fastapi_server.server` + Fassaden) | Settings, App-Fabrik, Prozessstart, CLI | uvicorn, console_scripts |

Nutzen: Naht kennen = austauschen ohne Fremdcode ändern. Stabilität: Recorder-Signatur testgefroren (TS7-02); Engine-Basis schmal (TS7-09); Session-API breit/intern (TS7-19); Serverstart mit Legacy-Pfad (C-07.03-3).

## 3. Recorder (TS7-01..TS7-08)

**Import (TS7-01):** 8 Namen via `__all__`, lazy `__getattr__`, kein Engine-/Torch-Import beim Import. Tippfehler fällt erst beim Zugriff auf.

**86-Parameter-Signatur (TS7-02):** alle POSITIONAL_OR_KEYWORD, Reihenfolge/Defaults testgepinnt (`test_audio_recorder_public_api.py`). Immer Keywords; Erweiterung nur hinten mit Default. Docstring-Abweichung compute_type: Signatur `int8` gilt (C-07.03-1).

**Fassade/Gates (TS7-03):** 8 Methoden (start/stop/listen/wait_audio/text/transcribe/perform_final/feed_audio) + 5 Controlled-Gates + wakeup/abort/shutdown + enter/exit. 20 private Wrapper per Test verboten: eine sichtbare Fassade, keine versteckten Proxys.

**Executor (TS7-04):** Pflicht `transcribe(audio,language,use_prompt)`, optional `transcribe_with_context`; sonst Callable. Ursache für hasattr-Naht (C-07.03-5).

**Konstanten (TS7-05):** INIT_MODEL_TRANSCRIPTION=tiny, SILERO_SENSITIVITY=0.4, SAMPLE_RATE=16000, BUFFER_SIZE=512, ALLOWED_LATENCY_LIMIT=100, DEACTIVITY_SILENCE_CONFIRMATION_DURATION=0.16 (testgepinnt).

**Init-Naht (TS7-06):** `build_recorder_init_args` + `initialize_recorder` (3 Callbacks). Aufbau ändern = Konfigurationsfunktion ändern, nicht Konstruktor.

**Client (TS7-07):** Remote-Fassade feed_audio(chunk,meta,rate=16000), set/get_parameter, call_method; keine Engine-Optionen (Serverseite entscheidet).

**AudioInput (TS7-08):** AudioInput(None,False,16000,1024,paInt16,1ch,True); öffnet keinen Stream (Beschreibung, keine Öffnung).

## 4. Engine (TS7-09..TS7-16)

**Basis (TS7-09):** engine_name=base, supports_streaming=False, warmup(audio), abstrakt transcribe; create_streaming_session = definierter Fehler. Fähigkeit abfragen, nicht raten.

**Streaming (TS7-10):** abstrakt reset/accept_audio(audio,rate)/get_result; konkret decode/finish/close. Nur Kroko bedient den Pfad.

**Typen (TS7-11):** Config = 12 Felder (model, download_root, compute_type, gpu_device_index, device, beam_size, initial_prompt, suppress_tokens, batch_size, vad_filter, normalize_audio, engine_options); Info 2, Result 3; model Pflicht, compute Default, batch 0.

**Faster-Ergebnis (TS7-12):** duration, duration_after_vad, segments[] (id/seek/start/end/text/tokens/temp/logprob/ratio/no_speech/words), words[] (word/start/end/prob). An Faster Whisper gebunden, nicht an Basis.

**Fabrik (TS7-13):** ENGINE_CLASS_PATHS nur faster_whisper + kroko_onnx; Default faster_whisper; erzwingt cpu/0. Dritte Engine = hier registrieren; GPU nicht über diesen Weg.

**Engines (TS7-14/TS7-15):** FasterWhisper (WhisperModel immer, BatchedPipeline nur bei batch_size>0; transcribe + nur-hier transcribe_with_options) vs KrokoOnnx (supports_streaming=True; __init__(config,backend,backend_cls); create_streaming_session/close). Asymmetrie = Stand der Produktpfade (N-07.03-1/2, C-07.03-5/6).

**Drei Bau-Stellen (TS7-16):** Recorder-Final (Kindprozess), Recorder-Realtime, Server-Lanes – alle via create_transcription_engine. Auswahl ändern = Fabrik ändern.

## 5. Session (TS7-17..TS7-21)

**Objekt (TS7-17):** RecorderBackedRealtimeSession(service,session_id,client_id,settings,session_config,activation_config,canonical_ids); Defaults aus service.settings.

**Implizite Fläche (TS7-18):** set_activation_policy, flush_buffered_audio, shutdown, abort, feed_audio(samples,rate=16000), open/close/abort_controlled, controlled_*_state, text. Eigener Recorder muss diese Menge bedienen, nicht nur die 8 Methoden (Falle: Test pinnt Fassade, Session nutzt Gates).

**API (TS7-19):** start/stop_streaming, close, clear, ingest_audio_packet, apply_settings_patch, snapshot, public_settings, trigger_command, protocol_replay_*. snapshot vs public_settings = intern vs außen. Drahtformate → 04.x.

**Fabrik (TS7-20):** admit_session(session_id,wake_word_request=None,client_id=None,activation_request=None,canonical_ids=False); 15.0 s initial, 3.0 s Followup (Timing-Katalog, keine Streuänderung).
