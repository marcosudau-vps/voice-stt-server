## Einordnung

Die aktuelle, fachlich maßgebliche Fassung liegt ausschließlich unter [docs/v2-handbuch](../../v2-handbuch/README.md). Diese archivierte Autorenfassung ist **kein zweites aktuelles Handbuch** und darf nicht unbesehen als aktuelle Produktbeschreibung zitiert werden.

Beim Vorabvergleich stimmten 103 von 105 ursprünglichen Handbuchdateien bytegenau mit der übernommenen Fassung überein; zwei Dateien wurden bei der Integration überarbeitet. Die historische Fassung bleibt hier zur Nachvollziehbarkeit separat erhalten.

Die hier abgelegte Arbeitskopie wurde für das öffentliche Repository redaktionell neutralisiert: lokale Windows-Benutzerpfade und bloße Nennungen eines früheren Projektnamens wurden ersetzt. Die unveränderten Originaldateien bleiben im lokalen Autorenarbeitsplatz.

Nicht übernommen wurden temporäre Python-Bytecode-Dateien und die 105 separat erzeugten MP3-Audioausgaben, da sie keine bearbeitbaren Dokumentationsquellen sind. Produktionscode, Lizenzbestand und V2-Produktverhalten wurden hierfür nicht verändert.
