erhöht `engine.frame_index` nie.

## 7. F13 – Exactly-once Eventing

Faulttests gegen den Admission-Coordinator:

```text
A  Fehler vor dem logischen Mint      -> ledger.count() == 0, kein Latch
B  Transportfehler nach dem Mint      -> ledger.count() == 1, delivered False,
                                         Latch und Activation bleiben
C  Retry (redeliver)                  -> ledger.count() == 1, genau 1 Zustellung,
```
