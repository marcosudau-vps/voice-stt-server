```text
minReceptiveFieldMs = 1960

```

Genau diese beiden gemessenen Werte sind die Bereichsgrenzen der neuen
Settingskeys:

```text
wakeWord.preRollMs   0 .. 1960   (kleinstes gemessenes Empfangsfenster)
wakeWord.cooldownMs  0 .. 3400   (größtes gemessenes Empfangsfenster)
```

Die verbindliche Entprellung einer Session ist das gemessene Empfangsfenster
der **tatsächlich gewählten** Modelle; `wakeWord.cooldownMs` ist ein
zusätzlicher Betreiberwert darüber. Beide Defaults sind `0`.
