# Korrekturbericht – AP-SRV-010 / Run 02_CORRECTION

**Status:** PASS

## Root-Befund und Korrektur

Der Run-01-Produktdiff benötigte keine Korrektur. Die Verdichtung des
Controller-Testmoduls von 41 auf 16 Testmethoden hatte jedoch weiterhin
gültige Baselineinvarianten nur implizit oder gar nicht erhalten. Run 02 stellt
diese als explizite Zieltests wieder her. Das Controller-Modul besitzt nun 32
Testmethoden plus 15 Subtests; zusätzlich bleiben die zielrelevanten Gate-,
Contract- und WebSocket-E2E-Nachweise erhalten.

Neu explizit geprüft werden Version/Sequenz, doppelte Recorder-Callbacks,
wiederholte Close-Kommandos, Timer ohne Deadline, monotone Zeit,
Snapshot-Leserraces, beide deterministischen Triggerreihenfolgen, additive
Extension in Waiting und Follow-up sowie Reset über alle vier nicht-idle
Phasen. Session-Close und Reconnect werden durch die bestehenden E2E-Tests
exakt referenziert.
