# AP-SRV-070 / W4AB-C1 — Requirement Matrix

|---|---|---|---|
| A | Linux variant tagging | IMPLEMENTED / TESTED / PASS | In `VoiceSTT/install_kroko.py` implementiert `retag_linux_wheel(...)`. Schreibt `1free`/`1pro` im Wheel-Dateinamen und in `*.dist-info/WHEEL` (`Build:`), aktualisiert `RECORD`-Hash/Größe atomar via `.part`. Getestet in `tests/unit/test_install_kroko_cpu.py` und `tests/unit/test_kroko_artifact_store.py`. |
| B | Linux OpenSSL/toolchain fingerprint | IMPLEMENTED / TESTED / PASS | In `VoiceSTT/install_kroko.py` und `VoiceSTT/kroko/fingerprint.py` erfasst `detect_linux_openssl_identity(...)` Header/Libs mit SHA-256 für System-Stack und expliziten Root. Linux-Builder-Revision wurde in `buildinputs.py` (`LINUX_BUILDER_REVISION = 1`) isoliert; Windows-Fingerprint bleibt stabil bei `28594e6d201fc4a7`. Getestet in `tests/unit/test_kroko_fingerprint.py`. |
| C | Free+Pro coexistence | IMPLEMENTED / TESTED / PASS | In `VoiceSTT/kroko/artifacts.py` sind Free- und Pro-Artefakte in separaten Namespace-Unterverzeichnissen (`free/`, `pro/`) abgelegt. Unabhängiges Lookup, Verify, Rebuild und isolierte Locks pro `(variant, fingerprint)` sichergestellt. Getestet in `tests/unit/test_kroko_artifact_store.py`. |
| D | Retention/GC | IMPLEMENTED / TESTED / PASS | In `VoiceSTT/kroko/artifacts.py` implementiert `KrokoArtifactStore.cleanup_obsolete(...)` Best-Effort-Retention (Default 30 Tage, `0` zum Deaktivieren). Aktueller Fingerprint und neuestes verifiziertes LKG bleiben geschützt; Traversal/Symlink-Prüfung und Lock-Schutz verhindern Datenverlust. Getestet in `tests/unit/test_kroko_artifact_store.py`. |
| E | Key != license/runtime authority | IMPLEMENTED / TESTED / PASS | In `VoiceSTT_server/stt_model_management.py` und `api_fastapi_server/server.py` wurde `kroko_pro_license_present` aus OperatorIntent und Eligibility entfernt. Key ist nur Runtime-Credential und entscheidet niemals über Variante oder Modell-Eligibility. Getestet in `tests/unit/test_stt_model_management.py`. |
| F | deterministic runtime variant | IMPLEMENTED / TESTED / PASS | Deterministische Prioritätskette: STT-Engine-Settings > Final-Optionen > Realtime-Optionen > Env (`VOICESTT_KROKO_VARIANT`) > Default `free`. Kein automatisches Umschalten auf `pro` bei Vorhandensein eines Keys; `config.yaml` setzt Default `free`. Getestet in `tests/unit/test_stt_model_management.py`. |
| G | resolved-engine options | IMPLEMENTED / TESTED / PASS | In `api_fastapi_server/server.py` liefert `resolved_engine_options(...)` Optionen ausschließlich für die tatsächlich aufgelöste Engine (Lane-spezifisch, dann andere Lane, dann Defaults). Probe, Worker, Recovery, Switch und Refresh nutzen diese isolierten Optionen. Getestet in `tests/unit/test_fastapi_server_multi_user_asr_integration.py` und `tests/unit/test_server_operations.py`. |
| H | secret boundary | IMPLEMENTED / TESTED / PASS | In `VoiceSTT_server/credential_redaction.py` implementiert: Redaktion aller Kroko-Key-Aliase und Env-Vars in Konfigurationsprojektionen, Audits, Logs und Fehlermeldungen (`_safe_stt_error`). Nachbarfelder bleiben erhalten. Getestet in `tests/unit/test_stt_model_management.py` und zentralem Event-Logging-Test. |
| I | refresh semantics | IMPLEMENTED / TESTED / PASS | In `api_fastapi_server/server.py` persistiert PATCH modellbezogene Absichten ohne Download und setzt `modelRefreshRequired`. Erst `POST /api/models/refresh` führt die transaktionale Modellaktualisierung aus; bei Fehlern bleibt LKG erhalten und Pending true. Getestet in `tests/unit/test_fastapi_server_multi_user_asr_integration.py`. |
| J | cross-platform wheel fixtures | IMPLEMENTED / TESTED / PASS | In `tests/unit/test_kroko_artifact_store.py` erzeugen Test-Fixtures zielplattformgerechte Wheel-Tags und -Architekturen. Plattform-Mismatch (Windows-Fingerprint mit Linux-Wheel bzw. umgekehrt) wird symmetrisch strikt abgelehnt. Getestet in `tests/unit/test_kroko_artifact_store.py`. |
