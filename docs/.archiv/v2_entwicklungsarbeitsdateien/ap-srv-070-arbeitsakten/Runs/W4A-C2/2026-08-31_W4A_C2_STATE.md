## 4. Artifact-Store-Vertrag (Ergänzung)

`KrokoArtifactStore._slot_lock()` ist jetzt ein echtes OS-Advisory-Lock auf
einem dauerhaft offenen Handle (`fcntl.flock` POSIX / `msvcrt.locking`
Windows). Die Lock-Datei wird bewusst **nie gelöscht** (vermeidet die
Unlink-Race); nur der OS-Lock-Zustand entscheidet über Exklusivität. Beobachtbares
Nebenprodukt: der Lock-Ordner enthält nach jeder Operation genau eine
persistente Marker-Datei pro benutztem Slot statt (wie unter C1) leer zu
sein. `adopt_existing`-/Force-Rebuild-Semantik aus C1 unverändert.
